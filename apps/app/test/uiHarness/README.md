# A조원 화면 상호작용·반응형 검수

새 패키지 없이 저장소에 이미 있는 Vite·React DOM·Playwright와 설치된 Chromium으로 **실제 A 화면 컴포넌트**를 실행합니다. 이 폴더의 React Native DOM 어댑터·지도·권한·센서 대체물은 테스트 전용입니다. 배포용 웹앱이나 Android 에뮬레이터가 아니며, 공용 Expo/Metro 설정을 변경하지 않습니다.

```sh
# 저장소 루트에서, 설치된 Chromium 경로를 지정할 수 있습니다.
CAMPO_CHROMIUM=/usr/bin/chromium node apps/app/test/uiHarness/check.mjs
```

검사기가 loopback Vite 서버를 시작하고 Chromium에서 실행한 뒤 자신이 시작한 서버를 종료합니다. 이미 실행 중인 검수 서버를 쓸 때만 `CAMPO_UI_URL=http://127.0.0.1:5199/`를 지정합니다. 결과 위치는 `CAMPO_UI_RESULTS`로 지정할 수 있고 기본값은 시스템 임시 폴더의 `campo-a-ui`입니다.

- 5개 탭·상세 유지·뒤로가기
- 논술 날짜/검색/체크리스트/즐겨찾기/지도 전달
- 축제 날짜/분류/검색/세 동선 버튼/즐겨찾기
- 행사 분류/검색/상세/즐겨찾기/지도 전달
- 보행 방식→지도 옵션, 권한 거절 후 수동 사용
- 가상 수동 경로 계산/출발·도착 교환/초기화/지도 선택 취소
- 실내 fixture 경로·층 보기, 다른 탭 길찾기 시 가상 지도 제거
- 320×568 / 390×844 / 430×932 / 1024×1366 / 320×568 글씨 1.6배에서 탭 터치 크기·하단 탭 노출·페이지 수평/수직 넘침 확인, 탭별 PNG 25장 저장

이 검사는 앱의 이벤트 처리·React 상태·기존 경로 엔진 연결을 검증합니다. 네이티브 지도 제스처/타일/글꼴 계측, 실제 키보드·노치·TalkBack, GPS/기압/사진은 검증하지 않습니다. 해당 항목은 Android 실기기 미검증으로 남습니다. DOM 어댑터의 이미지를 실제 앱 스크린샷으로 제시하지 마세요.
