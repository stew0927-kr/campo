# Push·PR 전 품질 검증 (2026-11-21, 한국 시간)

## 판단

검토용 Push·PR을 요청할 수 있는 상태입니다. Android 설치·실행이나 현장
길찾기 성공을 보장하지 않습니다. 이번 작업에서는 Push·PR·Merge·배포를
실행하지 않았습니다. 실제 서버 접근과 실기기 검증은 아래 제한과 함께
리뷰어에게 전달해야 합니다.

## Git·담당 범위

- 시작 브랜치 `feat/app-map`, 시작 커밋 `7e2588b`, 시작 작업 트리 깨끗함.
  기존 `e67a76c`와 A조원 커밋은 조상으로 유지합니다.
- 로컬 `main`은 없습니다. 기존 Fork 기준은 `origin/main` (`8aba711`),
  HTTPS로 새로 조회한 팀 원본 main은 `team-review/main` (`bfaa84d`)입니다.
- 시작 시 Fork main 대비 116개 파일 차이 중 39개는 관리자 웹·사진 파이프라인·
  SQL 0004/0005 등 이미 통합된 팀원 변경입니다. 해당 39개는 팀 main의
  변경과 일치합니다. 이를 A조원이 만든 변경이라고 분류하지 않습니다.
- 시작 시 최신 팀 main 대비 77개 파일은 모두 `apps/app/App.tsx`,
  `src/features/**`, `src/state/**`, `src/ui/**`, `test/**` 안입니다.
  이번 점검도 같은 범위이며 본 보고서가 추가됩니다.
- `git rev-list --count HEAD..team-review/main` = 0. 팀 main은 이미 조상이며
  `git merge-tree --write-tree HEAD team-review/main` 충돌 없음. 이 명령은
  사전 계산만 하며 브랜치·인덱스·작업 트리를 병합하지 않습니다.
  이후 팀 main이 바뀌면 다시 비교해야 합니다.
- A 변경의 현재 파일과 커밋 패치에서 자격 증명 패턴 검사 결과 0건.
  앱 담당 코드의 console.log/debug·debugger 0건. 검토 중 실제 개인정보를
  발견하지 않았으며 테스트 인물·장소는 가상 값입니다. 패턴 검사가 모든
  비밀정보의 부재를 수학적으로 보장하는 것은 아닙니다.
- `.env.local`, Android 내보내기 `dist/`는 Git 제외를 확인했습니다.
  실제 연결 값·스크린샷·로그·임시 캐시는 커밋하지 않습니다. 앱에서 공개
  publishable 키를 쓰며 관리자·service_role 키는 사용하지 않습니다.
- `__DEV__` 가상 캠퍼스 시험 버튼과 UI harness는 의도된 개발/검수 코드입니다.
  실제 캠퍼스로 표시하지 않으며 production에는 개발 버튼이 표시되지 않습니다.

## 실제로 수정한 오류

지도에서 '출발 선택'을 누른 채 다른 탭의 '여기까지 길찾기'를 누르면
이전 지도 선택 모드가 남았습니다. 추가한 화면 테스트에서 `1 !== 0`으로
재현했습니다. MapScreen의 새 목적지 처리에서 `setMapPick(null)`을 호출해
종료하도록 수정했고 동일 테스트를 포함한 화면 검사 20개가 통과했습니다.
이후 전체 타입·자동 검사 및 Android JS 번들을 통과했습니다.

기존 테스트의 단언은 약화하지 않았습니다. 테스트용 지도에 캠퍼스 밖 좌표
선택 버튼과 HTTP 응답 변형을 추가해 아래 예외를 실제 화면 이벤트로
확인했습니다. 배포용 지도·서버·공용 설정은 바꾸지 않았습니다.

## 화면·접근성 검토와 한계

DOM 어댑터로 320×568 / 390×844 / 430×932 / 1024×1366 및 320×568
글씨 1.6배에서 5개 탭별 PNG 25장을 생성했습니다. 문서 전체 수평/수직
넘침 없음, 하단 탭 노출, 탭별 최소 44×44 터치 크기를 자동 확인했습니다.
작은 지도·큰 축제·글씨 확대 내정보 캡처도 시각 검토했습니다. 모든 상세
화면의 모든 텍스트를 각 크기별로 시각 검수한 것은 아닙니다.

코드 검토만 완료한 항목: ScrollView/FlatList의 키보드 탭 유지,
KeyboardAvoidingView, 모달 SafeArea, 고정 하단 탭과 스크롤 영역 분리,
접근성 역할·선택/비활성 상태, 버튼/체크 최소 높이 및 글자 확대 대응.
DOM 어댑터는 실제 RN·지도·사진·GPS·센서를 대체하므로 Android의
키보드/노치/제스처/TalkBack/네이티브 글꼴을 검증했다고 주장하지 않습니다.

## 미검증·외부 조건

- 실제 Supabase 공개 GET을 다시 시도했으나 프록시 CONNECT 403으로 차단.
  인증·실제 행·RLS·실사진 응답은 미검증. 서버·보안 규칙 변경 없음.
- C조원의 실제 캠퍼스 노드/엣지·실내외 연결·목적지 ID가 필요합니다.
  fixture 결과는 실제 캠퍼스 현장 경로 성공이 아닙니다.
- MapLibre 포함 Android 앱에서 설치·지도 타일/선/핀·사진·권한·GPS·층 이동·
  장시간 안내·키보드·접근성·기기별 레이아웃을 직접 확인해야 합니다.
- 개인정보처리방침/문의처, 배포 전 전체 네이티브 라이선스 등 기존 외부
  준비 항목은 유지합니다. 이번 판정은 팀원 검토용이며 배포 승인과 다릅니다.
