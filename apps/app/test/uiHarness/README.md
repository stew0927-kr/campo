# A조원 화면 상호작용·반응형 검수

새 패키지 없이 저장소에 이미 있는 Vite·React DOM·Playwright와 설치된 Chromium으로 **실제 A 화면 컴포넌트**를 실행합니다. 이 폴더의 React Native DOM 어댑터·지도·권한·센서 대체물은 테스트 전용입니다. 배포용 웹앱이나 Android 에뮬레이터가 아니며, 공용 Expo/Metro 설정을 변경하지 않습니다.

```sh
# 저장소 루트에서, 설치된 Chromium 경로를 지정할 수 있습니다.
CAMPO_CHROMIUM=/usr/bin/chromium node apps/app/test/uiHarness/check.mjs
```

`CAMPO_UI_ONLY=<정규식>`은 이름이 맞는 시나리오만 돌립니다(디버깅용, 검수는 전체 실행). 검사기가 loopback Vite 서버를 시작하고 Chromium에서 실행한 뒤 자신이 시작한 서버를 종료합니다. 이미 실행 중인 검수 서버를 쓸 때만 `CAMPO_UI_URL=http://127.0.0.1:5199/`를 지정합니다. 결과 위치는 `CAMPO_UI_RESULTS`로 지정할 수 있고 기본값은 시스템 임시 폴더의 `campo-a-ui`입니다.

- 5개 탭·상세 유지·뒤로가기
- 논술 날짜/검색/체크리스트/즐겨찾기/지도 전달
- 축제 날짜/분류/검색/세 동선 버튼/즐겨찾기
- 행사 분류/검색/상세/즐겨찾기/지도 전달
- 보행 방식→지도 옵션, 권한 거절 후 수동 사용
- 가상 수동 경로 계산/출발·도착 교환/초기화/지도 선택 취소
- 실내 fixture 경로·층 보기, 다른 탭 길찾기 시 가상 지도 제거
- 공개 서버 응답/빈 응답/접속 실패/사진 실패는 모의 HTTP로 확인하며 실제 서버 성공으로 간주하지 않습니다.
- 다른 탭 길찾기 시 이전 지도 선택 상태 해제, 존재하지 않는 서버 노드의 검색 대체, 빈 검색·캠퍼스 밖 경로 실패 안내
- 지도 반화면 검색: 건물 선택 시 카메라 이동·검색 닫기/접기 후 카메라·건물 표시 유지(검색어 있는 선택, 층까지 들어간 경우, 실외로 나간 뒤, 다른 탭 다녀온 뒤)
- `←`(선택 취소)·하드웨어 뒤로가기: 검색어 복귀(앞뒤 공백 정리), 지도·목록 선택, 빈 문자열·공백·결과 없음, 출발/도착 지정 뒤, 지도 첫 화면에서는 OS로 넘김
- 건물 토글·층 카드: ON/OFF, ✕·`지도에서 계속 보기`·뒤로가기, 지금 보는 층 표시, 실내에서 다른 건물, 1개 층 즉시 진입, 층 없는 건물·층 미확인 장소, 실내 데이터 없음
- 화장실 찾기: 전체/남자/여자 목록(남녀공용·가족·미지정·알 수 없는 값은 양쪽), 성별 먼저 고르기, 성별 × 휠체어 6조합, 결과 없음 안내 3종, 필터 유지/초기화
- 길찾기: 이동 방식 5종 단독 선택·시트/접힌 바/지도 수치 일치, 휠체어 스위치, 왕복 토글, 실제 `RoadviewScreen`(단일 8장면 이동·전체화면·닫기·뒤로가기, 왕복 `가는 길`/`오는 길`, 갈림길 다른 방향), 다른 탭 복귀, 옵션 변경 시 말풍선·로드뷰 초기화
- 320×568 / 390×844 / 430×932 / 1024×1366 / 320×568 글씨 1.6배에서 탭 터치 크기·하단 탭 노출·페이지 수평/수직 넘침 확인, 탭별 PNG 25장 저장

이 검사는 앱의 이벤트 처리·React 상태·기존 경로 엔진 연결을 검증합니다. 네이티브 지도 제스처/타일/글꼴 계측, 실제 키보드·노치·TalkBack, GPS/기압/사진은 검증하지 않습니다. 해당 항목은 Android 실기기 미검증으로 남습니다. DOM 어댑터의 이미지를 실제 앱 스크린샷으로 제시하지 마세요.

### 테스트 전용 대체물

- `map.tsx`: 지도 대신 카메라 요청(횟수·위치·배율), 선택, 건물 강조·검색 건물, 실내 층, 경로 거리, 사진 지점·경로 사진 묶음, 로드뷰 말풍선을 글자·버튼으로 보입니다.
- 로드뷰는 실제 `RoadviewScreen`을 실행하고 네이티브 미니 지도(`miniMap.tsx`)와 `expo-image`(`image.tsx`)만 바꿉니다.
- `indoorFixture.ts`: 주소에 `?fixture=edge`가 있을 때만 실내 시험 데이터에 남녀공용·가족·성별 미지정·알 수 없는 값 화장실, 층 미확인 장소, 층 없는 건물을 더합니다. `src/`·`data/`의 데이터는 바꾸지 않습니다.
