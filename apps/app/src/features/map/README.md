# 지도 화면

`MapScreen`은 기존 `useCampusData`와 `useCampusRoute` 계약을 호출하는 화면입니다. 길찾기 엔진을 복제하거나 변경하지 않습니다.

- 기본 실행: 한양대학교 서울캠퍼스 지도 + 수동 출발·도착 검색. GPS 권한은 ‘현재 위치’를 눌러야 요청합니다.
- 장소·건물명·강의실 호수로 검색합니다. 선택이나 이동 방식이 바뀌면 이전 경로를 지워, 다른 입력의 결과가 남지 않게 합니다.
- `polyline`을 GeoJSON 경로선으로 바꾸고 지도 범위를 맞춥니다. 안내 문장·층 이동·경사 경고는 계약의 값을 그대로 보여 줍니다.
- 실제 데이터가 비어 있으면 이를 알립니다. 개발 빌드(`__DEV__`)의 ‘개발용 가상 경로 시험하기’를 누른 뒤 ‘가상 시험 지점 1’과 ‘가상 시험 지점 3’을 선택해 연결을 시험할 수 있습니다. 가상 데이터는 화면에 명시되며 실제 지리·경로 정확성을 보장하지 않습니다. 배포 빌드에서는 이 전환 버튼이 없습니다.
- 다른 탭은 준비 중 화면입니다. Supabase 데이터 연동·실시간 GPS 추적·사진 길안내는 이번 화면 작업 범위에 포함하지 않습니다.

저장소 루트에서 화면 연결 테스트:

```sh
npx vitest run --config apps/app/src/features/map/vitest.config.mts
```

공용 테스트 설정을 바꾸지 않아 이 테스트는 위 명령으로 별도 실행합니다. 검색, 수동 요청, 기존 엔진 결과의 좌표 변환, 이동 방식, 잘못된 지점과 같은 지점 경로를 검증합니다. `npm run typecheck`와 `npm test`도 루트에서 실행합니다.

Android 개발 빌드에서 추가 확인할 것:

1. `npm run app` 후 MapLibre가 포함된 개발 APK로 연결합니다(Expo Go는 지원하지 않습니다).
2. 첫 지도 중심·OSM 출처·타일 로딩, 키보드가 열린 검색창과 작은 화면·큰 글씨를 확인합니다.
3. 위치 권한을 거절한 상태에서 가상 지점으로 수동 길찾기 → 경로선·거리·시간·이동 안내를 확인합니다.
4. 현재 위치 권한 허용·거절·기기 GPS 끔, 경로를 찾지 못하는 경우를 확인합니다.
5. 다른 탭으로 이동 후 돌아왔을 때 입력과 경로가 유지되는지 확인합니다.
6. 실제 데이터가 등록되면 건물·강의실 검색과 실제 경로 정확성·층 이동 안내를 현장에서 확인합니다.
